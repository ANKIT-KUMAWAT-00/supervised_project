# LIBRΛ — Smart Library Occupancy & Resource Intelligence System
> "The Intelligence Behind Every Study Space."

## Project Overview
LIBRΛ is an AI-driven Smart Library Occupancy & Resource Intelligence platform designed as a futuristic digital twin command center. It bridges real-time IoT hardware telemetry with predictive machine learning algorithms to eliminate seat search times, forecast multi-horizon space congestion, and optimize academic resource allocations.

### Key Highlights
- **Interactive 3D Digital Twin Library:** Procedural 4-floor architectural model with 120 seats and real-time status.
- **AI Multi-Horizon Forecasting Engine:** Benchmarks Linear Regression, Random Forest, and XGBoost ($R^2 = 0.9533$) across 30m, 1h, 3h, 6h, and 24h horizons.
- **Interactive 3D ML Laboratory:** Visualizing decision trees in 3D space, regression surfaces, and cloud points.
- **Intelligent Recommendations & Assistant:** Personalized study space suggestions and conversational AI assistant.
